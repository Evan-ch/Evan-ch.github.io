# 微信开发者配置

微信生态下开放的接口能力越来越多，借此文章说明下微信生态下常见场景开发需要准备的前置条件

# 公众号

不管目前是否有公众号需求都建议先注册服务号类型的公众号，公众号的认证后可以复用于小程序、企业微信、腾讯云、商户号认证，无需再次等待审核和交纳认证费用。 以上认证复用在2024年后无法实现，需要个应用单独认证

  1. 使用管理员登录微信公众平台： 微信公众平台 (opens new window)
  2. 选择类型为服务号
  3. 根据指引流程完成注册后，点击头像，认证详情进行认证。

# 小程序

小程序用于比公众号的开放能力，开发者能获取更多的权限开发应用

  1. 进入公众号的小程序管理菜单，点击添加
  2. 选择快速注册并认证小程序，如果已注册小程序，则选择关联小程序
  3. 管理员授权后填写相关内容即可关联小程序
  4. 如果公众号没有认证需要进行认证，认证后方可开通接口权限

# 微信商户号

在微信公众号、小程序或者web网页、app中接入微信支付收款和付款，需要开通支付号，联系我们开通特约商户可申请低至0.2%费率。

  1. 进入小程序管理页面，点击微信支付-接入微信支付-申请接入
  2. 在线提交营业执照、身份证、银行账户等资料，并完成账户验证。
  3. 复制上图appid后，点击前往或登录https://pay.weixin.qq.com/ 商户号后台绑定
  4. 完成绑定后，可在小程序绑定商户号列表中查到已绑定商户号

开通支付产品，（根据需求开通对应的支付产品，例如用于营销活动的现金红包）

  1. 登录商户号后台，点击产品中心-运营工具-现金红包
  2. 根据申请流程填写相关资料进行开通

现金红包开通条件：商户号注册满90天，连续不间断30天存在交易流水

  1. 配置接口权限信息
  2. 运营账户充值

# 微信开放平台

小程序和公众号进行关联后，只是可以在模板消息，菜单中跳转到小程序，但仍然无法打通小程序和公众号的用户。开放平台用于绑定公众号和小程序，使开发者能在公众号和小程序的统一unionid.

  1. 注册微信开放平台，并登陆，注册链接： 微信开放平台 (opens new window)
  2. 通过开发者认证
  3. 分别绑定公众号和小程序

# 企业微信认证和发布自建应用

企业微信主要应用于企业内部和上下游(客户、供应商、经销商)的办公协同，私域流量运营等场景

  1. 注册企业微信，并登陆，注册链接： 企业微信 (opens new window)
  2. 点击我的企业-前往认证
  3. 根据实际情况选择对应的规模进行认证流程
  4. 认证通过后可以在应用管理中创建开发的应用
  5. 上传logo,填写应用名称,和介绍后点击确定
  6. 配置应用主页为后台API服务url
  7. 设置企业可信IP为后台服务器的IP

# 企业微信自建应用开发要求

  1. 域名(和企业微信主体一致的已备案的域名，增加一个新的二级域名)
  2. 服务器登录权限（推荐版本，CentOS7.6）
  3. DNS配置（把新建二级域名，添加DNS解析记录指向提供的用于部署自建应用后台的服务器）
  4. 客户企业微信后台权限（提供联系人，或者我们后边提供配置手册客户用户进行配置）

# 腾讯云

部署开发应用需要购买域名、ssl证书、服务器，可以使用公众号身份认证进行实名认证。获取新用户优惠

  1. 点击腾讯云活动链接 腾讯云最新活动 (opens new window)
  2. 注册登录后需要进行实名认证
  3. 实名认证通过后可以在活动页面根据需要购买所需的云资源

开通使用相关云服务，以开通短信包示例

  1. 点击短信进入短信控制台
  2. 新增签名提交认证
  3. 新建模板提交审核
