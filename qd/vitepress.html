# vitepress替代ant-design-pro-landing和vuepress

之前一直使用ant-design-pro-landing模板作为产品官网的框架,使用vuepress搭建了产品文档中心站点,试用了一下vitepress,有美观的首页,也有带文档目录结构侧边栏页面,可以完美替代两者合并到一个站点中.于是就开始折腾了.

# 安装 node.js环境

  • 从Node官网下载,Node 18及以上.安装时确保勾选“Add to PATH”选项,不然需要安装后手动配置环境变量.

# 安装pnpm

推进使用pnpm代替npm,可以很大提升构建速度.

npm install --global pnpm
  • 安装后配置pnpm源为淘宝的源，下载速度快一些
pnpm config set registry https://registry.npmmirror.com

# 安装和初始化vitePress

pnpm add -D vitepress

# 初始化项目

pnpm vitepress init

# 按需调整内容(非必需,不影响运行)

  • 以下根据自己的内容进行调整index.md文件,style部分是标题和图片部分渐变色的自定义样式
---
# https://vitepress.dev/reference/default-theme-home-page
layout: home

hero:
  name: "成集云"
  text: "可视化集成异构系统  "
  tagline: 自动化全链流程
  image:
    src: jinei.png
    alt: cjclogo
  actions:
    - theme: brand
      text: 应用中心
      link: /markdown-examples
    - theme: alt
      text: 方案中心
      link: /api-examples

features:
  - title: 数据集成
    details: api/kafka/mq/数据库直等丰富的对接方式,专属安全通道,支持700+应用集成
  - title: 任务调度
    details: 新一代分布式任务调度平台,多种定时方式,失败重传预警,任务工作流编排,全程可控
  - title: 数据服务平台
    details: 主数据管理,数据质量管理,元数据管理,数据血缘分析,多端数据可视化
---

# 打包运行

# 启动本地服务
pnpm run docs:dev
# 编译部署
pnpm run docs:build
# 编译后本地预览
pnpm run docs:preview
