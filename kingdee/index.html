# 金蝶EAS和SHR Linux下启动和停止服务

公司用的财务系统，金蝶EAS8.0 和 SHR1.5 本来是同一个系列产品，在这个系列给拆开了分别两个中间件启动

  • 通过EAS服务端的"server/profiles/<实例名>/bin"目录下的"startserver.bat(sh) "和 "stopserver.bat(sh)"可分别启动与停止金蝶EAS实例对应的应用服务器。

  • 如果要启动图形界面的管理控制台停止管理控制台服务端可通过eas/admin 目录下stopserver.cmd（sh)

  • 群集环境启动脚本为eas\server\bin\startCluster.sh 停止脚本为eas\server\bin\stopCluster.sh

  • 网络代理启动脚本为eas\server\nap\startnap.sh,停止脚本为eas\server\nap\stopnap.sh

# K3客户端组件测试报错解决

一般出现此报错需要确认在客户端打开开始-程序-金蝶K3-金蝶K3工具-远程组件配置工具，输入K3服务器ip地址后单击【测试】确认是否正常，若测试通过后单击【确定】后则可正常使用，若【测试】不通过，请单击【终止】后查看测试结果：

  1. 若测试结果显示：需要对象，则需要您在客户端及服务器上设置同名同密码的操作系统用户；
  2. 若测试结果显示：不能作为远程服务器，请您检查服务器防火墙以及网络是否正常；
  3. 若提示：网络中间层连接失败，请您确认客户端与服务器版本是否一致；
  4. 若提示：确保中间层上组件为最新版本，请您检查客户端【组件服务】中的com+应用程序中是否有很多的ebo组件包，请删除，若是所有客户端请您将服务器上【添加删除windows组件中的“应用程序服务器”卸载后重新完全安装；
  5. 拒绝的权限，添加K3安装目录EVERYONE 完全访问 K3注册表EVERYONE完全访问

# 金蝶K3客户端匿名连接K3服务器

  1. 在“计算机管理”中建立一个新用户（用户名：k3mid ， 密码：k3midk3mid）；把默认的Administrator改成其它的名字（例：Admin），把Guest用户改名（Guest_kd）；
  2. 在“本地安全策略”->“本地策略”->“安全选项”中：
    • 将第一项“网络访问：本地账户的共享和安全模式 属性”改为“经典—本地用户以自己的身份验证” ；
    • 将“帐户：使用空白密码的本地帐户只允许进行控制台登录”禁用；
    • 将“账户：来宾账户状态”启用。
  3. 在“组件服务”（或运行Dcomcnfg命令）->“COM+ 应用程序”中，选择以“Ebo”开头， “EBOHRMS”这个除外，再加上“KDSVRMGR”这个组件，点“属性”->“标别”这个标签页，选择“下列用户”这个选项，把上面建的用户名与密码填入其中。再将“安全”标签页中的“调用身份级别”用“连接”，“模拟级别”用“标识”显示；
  4. 修改防火墙
  5. 在“组件服务”（或运行Dcomcnfg命令）->“我的电脑”->“属性”->“默认属性”->“启用分布式COM”打钩，还有“默认身份级别”用“无”，“默认模拟级别”用“匿 名”显示。

# 金蝶EAS 合并报表 集团下发模板新增

  • 在EAS主界面点击左上角【系统】，选择下拉列表切换组织，切换到集团层面。
  • 依次单击【战略管理】→【法定合并】→【基础设置】，双击【个别报表模板】，进入个别报表模板界面；
  • 在个别报表模板界面进行集团下发模板的新增，新增完毕后进行模板分配即可。

【说明】

  1. 新增的财务组织需要先添加到合并范围钟
  2. 在模板制作中的集团下发模板是不可以进行新增的，只需要集团层面把个别报表模板分配下来即可。

# 金蝶KIS商贸版忘记账套管理密码/非账套管理员密码

  1. 先尝试在该数据库AcctCommerce中清空，执行
update t_Users set FPassWord=null where FName='Admin'
go

  1. 然后提示登陆报错： 用户验证错误 'invalid use of null'

  2. 然后更新

update t_Users set FPassWord='0' where FName='Admin'
go

更新后空密码正常登陆;

  • 更新员工状态
update T_BD_Person set  FEmployeeTypeID =  '00000000-0000-0000-0000-000000000001A29E85B3'  where fname_l2 = 'xxx' ;
  • 更新人事事务单据状态(转正单为例)
update T_HR_EmpHireBizBill set FBillState = 3 where fid = 'xxxx=';
  • 更新流程实例状态和完成时间
select FSTATE,FCOMLETETIME,FLASTSTATETIME from T_WFR_ProcInst where FId = 'xxxx=';
  • 更新流程活动节点和完成时间
update T_WFR_ActInst  set FSTATE = 'closed.completed' ,FCOMLETETIME = '2024-12-04 15:33:59.317' where FACTINSTID ='xxxWFATINST'
  • 插入处理过的工作流任务和工作流任务中员工待办任务
insert into T_WFR_AssignHst(省略) values(****省略);
delete from T_WFR_Assign where FACTINSTID ='xxxx';

-- 人事事务单据表头 更新成审核通过,fbillid为单据的FId
